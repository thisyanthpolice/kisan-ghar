# kisan-ghar

Kisan Ghar - Connecting Farmers and Health-Conscious Consumers
Kisan Ghar is a platform designed to bridge the gap between local farmers and individuals who prioritize fresh, healthy produce. This web application facilitates direct access to a variety of farm-fresh fruits, vegetables, and curated health boxes designed by nutritionists.

made for :
Individuals seeking fresh, locally sourced produce.
Health-conscious consumers interested in nutritionist-designed food boxes.
Supporting local farmers and sustainable agriculture.

Key Features:

Selecting Products: Browse and purchase a wide range of fresh products directly from local farmers.
Health Boxes: Explore curated health boxes designed to meet various nutritional needs.
Nutrition Coach AI: Get personalized health and nutrition advice from an AI-powered coach.
Multilingual Support: Access the platform in multiple languages for a wider reach.(limited to southindian languages)

Technologies Used:
PHP
MySQL 
Tailwind CSS
HTML
JavaScript 

To Run Locally  :
Ensure you have a web server XAMPP with PHP installed.
Set up a database and import the necessary schema and data.
Configure the database connection details in db_connect.php.
Place the PHP files in your web server's document root.
Access the application through your web browser.
