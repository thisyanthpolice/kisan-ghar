# 🌾 Kisan Ghar

**Kisan Ghar - Connecting Farmers and Health-Conscious Consumers**  
Kisan Ghar is a platform designed to bridge the gap between local farmers and individuals who prioritize fresh, healthy produce. This web application enables direct access to a wide variety of farm-fresh fruits, vegetables, and curated health boxes designed by certified nutritionists.

---

## 🎯 Made For

- Individuals seeking **fresh, locally sourced produce**  
- Health-conscious consumers interested in **nutritionist-designed food boxes**  
- Supporting **local farmers and sustainable agriculture**

---

## ✨ Key Features

- **Selecting Products**: Browse and purchase a wide range of fresh products directly from local farmers.  
- **Health Boxes**: Curated by nutritionists to meet various health and nutritional needs.  
- **Nutrition Coach AI**: Get personalized health and nutrition advice through an AI-powered coach.  
- **Multilingual Support**: Accessible in multiple South Indian languages to reach a broader audience.

---

## 🚀 To Run Locally

1. Make sure you have a web server like **XAMPP** installed with PHP and MySQL.
2. Set up a MySQL database and import the required schema and data.
3. Update the database credentials in `db_connect.php`.
4. Place the project files into the `htdocs` directory (or your server’s document root).
5. Start Apache and MySQL from XAMPP.
6. Access the application through your browser at: `http://localhost/your-folder-name/`
